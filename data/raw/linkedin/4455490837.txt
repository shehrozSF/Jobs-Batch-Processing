- Optimize front-end and back-end systems for performance, reliability, and maintainability
- Collaborate with cross-functional teams across time zones
- Support and improve live production systems with a focus on uptime and data accuracy
- Participate in code reviews, system design discussions, and feature planning
- Explore opportunities to integrate AI-driven features and data automation

- Minimum 3+ years of professional full-stack development experience
- Strong proficiency in React, including component design, state management, responsive layouts, and performance optimization
- Good understanding of UI/UX principles, including visual hierarchy, spacing, typography, accessibility, and user-centered design
- Experience with modern CSS frameworks (Tailwind, Sass, Styled Components, Material UI, Chakra UI, etc.)
- Back-end development skills using Python (Flask/FastAPI/Django) or Node.js (Express/NestJS) to build APIs, integrations, and support front-end features
- Strong proficiency in either Python or JavaScript
- Solid understanding of Linux environments, SQL databases (PostgreSQL/MySQL), and back-end system design
- Ability to collaborate closely with product managers, designers, and back-end engineers
- Ability to independently handle end-to-end features (UI, API integration, testing, deployment)
- Experience contributing to complex or large-scale systems
